## Test Design

### calculateDiscount

Для тестування функції застосовано аналіз граничних значень для відсотка знижки, перевірку розрахункової логіки та обробку виняткових ситуацій:

- **Позитивні сценарії (розрахунок знижки):**
  - Стандартний розрахунок: `price = 100`, `percent = 10` => очікуваний результат `90`.
  - Нижня межа знижки (0%): `price = 100`, `percent = 0` => очікуваний результат `100`.
  - Верхня межа знижки (100%): `price = 100`, `percent = 100` => очікуваний результат `0`.
- **Негативні сценарії (обробка некоректних даних):**
  - Від'ємна ціна (`price < 0`): `price = -10`, `percent = 10` => викидання помилки `Error('Price must be a non-negative number')`.
  - Нечислова/нескінченна ціна: `price = NaN`, `price = Infinity` => викидання помилки `Error('Price must be a non-negative number')`.
  - Некоректний відсоток (`percent < 0` або `percent > 100` або `NaN`): `percent = -1`, `percent = 101`, `percent = NaN` => викидання помилки `Error('Discount must be between 0 and 100')`.

### validateQuantity

Застосовано техніки класів еквівалентності та аналізу граничних значень:

- **Класи еквівалентності (Equivalence Partitions):**
  - quantity < 1 (Invalid) => `false`
  - 1 <= quantity <= 10, ціле число (Valid) => `true`
  - quantity > 10 (Invalid) => `false`
  - Не ціле число (Invalid) => `false`

- **Граничні значення (Boundary Values & BVA Test Data):**
  - Нижня межа (1): значення `0` (очікується `false`), `1` (очікується `true`), `2` (очікується `true`).
  - Верхня межа (10): значення `9` (очікується `true`), `10` (очікується `true`), `11` (очікується `false`).
  - Перевірка на цілочисельність: значення `1.5` (очікується `false`).

Тестування реалізовано за допомогою параметризованого методу `test.for()`.

### getShippingCost

Застосовано техніку тестування гілок та граничних значень для суми замовлення:

- **Гілка 1 (`total < 0` або не число):**
  - `total = -1` => генерує `Error('Total must be a non-negative number')`.
  - `total = NaN` => генерує `Error('Total must be a non-negative number')`.
- **Гілка 2 (0 <= total < 1000 — платна доставка):**
  - Безпосередньо перед межею безкоштовної доставки: `total = 999` => очікується `100`.
- **Гілка 3 (total >= 1000 — безкоштовна доставка):**
  - На самій межі: `total = 1000` => очікується `0`.
